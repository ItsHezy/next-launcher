# ADR 0013: Tray, autostart, notifications, recovery, accessibility, notices

Status: Accepted (2026-10-30). The license (ADR 0001) and the app updater (ADR 0014) are decided since.

- **Tray, always present while the app runs.** Left click opens the window; the menu has Open,
  up to 8 Quick Launch games (launch directly; questions like save conflicts bring up the window),
  the current download with pause/resume, and Quit. The menu is rebuilt when the pointer reaches
  the icon, so it needs no change listeners.
- **Close to tray is on by default** (like the official launcher): the title-bar close, Alt+F4 and
  the taskbar's Close hide the window; Quit is in the tray menu. Reopening from the tray takes
  ~30 ms, which is the practical answer to the warm-start budget (a cold WebView2 start stays
  ~400 ms). A second start of the app shows the running instance.
- **Run at startup** writes one value under the user's `HKCU\...\CurrentVersion\Run` key only when
  the user turns it on and deletes it when they turn it off; development builds use a separate
  value name. "Start minimized" applies to those Windows-started launches only.
- **Notifications** through `tauri-plugin-notification` (+207 KB exe, +62 KB installer; below the
  500 KB line from the brief): download finished, this week's free games (only new ones), sound
  on/off, nothing while a game runs. News, chat and invites stay off (no source yet).
- **Crash-safe updates.** Applying a staged update writes a marker first; launch refuses while it
  exists, and re-running the apply after a crash (or after the moves but before the database was
  updated) finishes it. Downloads already resumed per file since Phase 4.
- **Accessibility** is checked with axe-core in the running app (`npm run a11y`, dev dependency)
  across 17 views, plus the brief's 44 px hit-target rule. Fixed: missing `main` landmark, store
  cards whose label hid their visible text. Dialogs keep Tab inside and return focus on close.
- **Third-party notices** are generated by `npm run licenses` (Windows dependency graph only):
  a summary in Settings → About and `THIRD-PARTY-NOTICES.txt` (full texts) shipped with the
  installer. No GPL/LGPL components; five MPL-2.0 crates (used unmodified).
- **Open for the owner:** installer signing (needs a code-signing certificate). The updater and
  release pipeline are in ADR 0014.
