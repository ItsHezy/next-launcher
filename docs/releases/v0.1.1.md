Games you installed with the Epic Games Launcher now show up in Next Launcher as installed, ready to play, without downloading them again.

- They're added automatically after each library refresh, if you own the game and the install is complete. Their folders and the Epic Games Launcher's files aren't changed.
- A game you uninstall in Next Launcher isn't added back.
- You can turn this off in Settings → Downloads & installs → "Add games from the Epic Games Launcher".
- The list of open-source components now includes the update system added in 0.1.0.
